=========================
COMO COMPILAR E EXECUTAR
=========================

Abrir o terminal na pasta design_patterns/ e rodar:

# Compilar tudo (de dentro de design_patterns)
  javac -d out (Get-ChildItem decorator\*.java, template_method\*.java)

# Rodar o Decorator
  java -cp out decorator.MainDecorator

# Rodar o Template Method
 java -cp out template_method.MainTemplate

Requer Java 17+ instalado.
